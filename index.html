Inside the analyzer

Everything you need to read traffic.

A focused subset of the Wireshark workflow, rebuilt for the browser.

Massive captures

No packet-count cap. Open captures up to 128 MB, decode them in chunks with progress, and scroll a virtualized packet list that stays responsive at any size.

Display filters

Use Wireshark syntax: boolean logic, parentheses, CIDR ranges, quoted strings, contains, matches and hex values.

Deep dissection

Explore Ethernet, VLAN, IPv4/IPv6, TCP, UDP, ICMP, ARP, HTTP, DNS, TLS, SSH and NTP down to individual fields.

Statistics

Explore a zoomable near-fullscreen radial traffic graph where every connection is its own node and every packet is a dot on its connection halo, ordered by capture time. Rich labels carry endpoints, protocol, packet and byte totals, duration and frame range, with an integrated packet story, a resizable details pane and a resizable map-aware AI chat that can explain the live view and propose map moves for approval. Right-click any packet dot or packet row to select it or ask the map analyst about that exact frame. Protocol hierarchy, conversations, endpoints, expert information and IO graphs are one click away.

Local triage

Run deterministic detectors for beaconing, scans, DNS anomalies, outbound asymmetry, cleartext credentials, ARP conflicts, lateral movement, rare protocols and long-lived flows. Start from the map toolbar or the ◆ Triage action in either AI chat. Every finding carries severity, confidence, an explanation, exact frame references, a display filter, entities and a next pivot, with actions to ask the AI, show it on the map, follow the stream, pin it or mark it benign. Detection never leaves the browser.

Investigation brief

Click Investigate for a ranked, evidence-led brief with an exact frame citation on every claim, next pivots, a case timeline and a clickable entity graph. Export a complete Markdown or standalone HTML report, and let the AI explain the ledger with citation checks. Local detection stays deterministic.

AI filter assistant

Describe the packets you want in plain language. The assistant proposes one display filter, then NETMAP validates it locally, reports the exact match count and previews frames before you apply anything. Edit, copy or explain the filter in plain language.

Case file

Pin findings, notes and packet references into one browser-local case, then export it as Markdown or JSON with credential values redacted. Evidence frames are added automatically when you pin a finding.

Capture comparison

Load a baseline capture to flag novel hosts, domains, service endpoints and MAC addresses with their first-seen frames and an exact frame filter, without replacing the active viewer.

Follow streams

Reassemble TCP or UDP conversations, switch direction, read ASCII or hex, and see the packet behind every byte.

Keyboard first

Find, go-to, marks, comments, zoom and menus are all one shortcut away. Press F1 inside the viewer for filter help.

AI analyst

Ask questions about the loaded capture with an OpenAI-compatible model, or open the analyst inside the traffic map to explain the live graph and trace a selection. The ◆ Triage suggestion runs the local detectors first and gives their evidence to the model for a grounded explanation. Inspect any packet with a local dossier or a deep, field-level AI analysis backed by read-only packet tools and clickable frame citations. Suggested filters, jumps, panels and map moves apply only when you approve them.
